# Ludothèque Monge

Tous les jeux de société de la coloc. On choisit en haut le nombre de joueurs et la liste ne garde que les jeux jouables à ce nombre, avec un pitch et l'ambiance de table pour chacun.

Le site tient dans un seul fichier, `index.html`, sans dépendance à installer. Il est servi par GitHub Pages.

Pour ajouter ou modifier un jeu, il suffit d'éditer le tableau `GAMES` dans le script en bas de `index.html`.
